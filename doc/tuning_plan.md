# 循跡 PID 調試計劃 (最簡版)

## 當前演算法

```
Gray_Read (active-LOW) → 加權平均 error(mm) → PD → 固定速度+差速 → 馬達

無濾波 / 無動態速度 / 無 edge detection / 無 encoder balance
```

## 參數

| 參數 | 值 | 說明 |
|------|:--:|------|
| FIXED_SPEED | 200 | 固定 PWM |
| RIGHT_TRIM | 35 | 右輪補償 |
| KP | 0.50 | 起點 |
| KD | 0 | 先不加 |

## Stage 1: 直線 P-only 找 Ku

```
KP: 0.5 → 0.8 → 1.1 → 1.4 → 1.7 → 2.0 → ...
      穩       穩      搖?     搖      震      Ku
```

每次 +0.3，直到出現**持續小幅左右震盪**。記錄該值為 Ku。

| 測試 | KP | 結果 |
|------|:--:|------|
| 1.1 | 0.5 | |
| 1.2 | 0.8 | |
| 1.3 | 1.1 | |
| 1.4 | 1.4 | |
| 1.5 | 1.7 | |
| 1.6 | 2.0 | |
| 1.7 | ... | Ku = ? |

## Stage 2: 加入 KD 阻尼

```
KP = Ku × 0.6
KD = Ku × 0.06 → Ku × 0.10 → Ku × 0.15
```

| 測試 | KP | KD | 直線 | 彎道 |
|------|:--:|:--:|------|------|
| 2.1 | Ku×0.6 | Ku×0.06 | | |
| 2.2 | Ku×0.6 | Ku×0.10 | | |
