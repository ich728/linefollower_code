# STM32 F407主控接口引腳定義配置表 (Pinout Definition)

本文件整理自電路板絲印標示，並依據指示進行分類：
* **左側排針**：代表 **近端 (Near End )**
* **右側排針**：代表 **遠端 (Far End )**
